# ⚙️ 机械机构示例库 · MECH ENGINE

> 带 **实时运动学仿真** 的机械传动机构参考库 · 科技风展示网页

一款纯静态、单文件的科技风机构展示页，内置 **257 种经典机械机构** 的实时运动学仿真动画。所有机构都由 JavaScript 按真实几何关系逐帧求解（而非预设逐帧动画），辅助机械设计选型与方案构思。**全部 257 种机构均支持参数化实时仿真** —— 点开任一机构卡片，即可在详情弹窗中拖动滑块实时调整几何尺寸（曲柄半径、连杆长度、齿数、锚点位置等）与动画速度 / 缩放，求解动画随参数即时重算。支持**全文搜索**、**分页浏览**与 **极夜 / 曜白 / 熔金** 三主题切换。

## ✨ 特性

- **实时运动学仿真** —— 曲柄滑块、四连杆连杆曲线、行星齿轮公转/自转、蜗轮蜗杆速比等均按真实几何实时计算，`requestAnimationFrame` 驱动
- **参数化实时仿真（全 257 种）** —— 详情弹窗内可拖动滑块实时修改机构几何参数（尺寸 / 杆长 / 齿数 / 锚点位置等）与动画速度、整体缩放，求解动画随参数即时重算，便于直观理解各参数对运动的影响
- **257 种机构 · 11 大分类** —— 连杆、凸轮、齿轮、间歇、螺旋、夹紧、液压、万向、挠性传动、机器人、仿生，支持分类筛选
- **全文搜索** —— 按名称 / 分类 / 英文名实时过滤机构卡片并显示命中数
- **分页浏览** —— 每页 12 项，上一页/下一页 + 页码跳转，搜索与筛选自动回到第 1 页
- **三主题切换** —— 极夜（深空青）/ 曜白（明亮）/ 熔金（暖色），本地记忆选择
- **详情弹窗** —— 点击任意卡片查看大图仿真 + 参数速查表 + 实时参数输入滑块（通用：动画速度 / 整体缩放；各机构另带几何级参数）
- **时间轴逐帧** —— 详情弹窗内可暂停并拖动时间轴，定格观察任意时刻机构姿态，便于讲解与截图
- **导出与分享** —— 一键将当前姿态导出为 SVG / PNG（含科技风样式）或参数 JSON；「复制分享链接」把机构与参数编码进 URL，打开即还原
- **经典预设** —— 部分机构（曲柄滑块 / 四连杆等）内置参数预设，一键载入典型工况（标准 / 偏置急回 / 双曲柄等）
- **纯静态单文件** —— 无任何依赖、无需构建、无需联网，双击即可打开
- **科技风 HUD 视觉** —— Orbitron / Rajdhani / 思源黑体字体搭配，青色 + 琥珀主色，蓝图网格、扫描线、切角按钮、角标光效
- **动效完善** —— 数字滚动、滚动显现、跑马灯（含 IntersectionObserver + 滚动兜底，兼容稳定）
- **响应式布局** —— 适配桌面 / 平板 / 手机

## 🧩 技术亮点

- **纯原生实现**：HTML + CSS + 原生 JS + SVG，无框架、无第三方库
- **运动学求解引擎**：
  - 曲柄滑块：由曲柄角实时解出滑块位置与连杆倾角
  - 四连杆：余弦定理求解 coupler，并实时描画连杆曲线
  - 行星齿轮：公转 + 自转（含速比换算），虚线内齿圈示意
  - 蜗轮蜗杆 / 齿轮泵 / 导杆急回等均含对应传动关系
- **参数化求解引擎**：每个机构的几何常量 / 锚点位置均可被 `inputs` 声明为滑块；弹窗将参数注入 `build(svg, p)`，重新执行后即时替换到渲染循环，无需刷新页面即可看到参数变化后的新运动
- **动效兜底**：数字计数与滚动显现同时使用 IntersectionObserver 与滚动检测，保证各环境稳定触发
- **无障碍细节**：按钮含 `aria-label`，SVG 带 `aria-label` 描述

## 🛠 如何新增一个机构

项目为单文件架构，扩展机构只需在 `index.html` 的 `MECHANISMS` 对象中新增一条：

```js
'my-mechanism': {
  name: '机构名称',
  en: 'MECH-EN',
  cat: '所属分类',            // 需与 CATS 数组中的分类一致
  idx: '101',
  desc: '一句描述',
  params: [['参数','值'], ['典型应用','...']],
  // inputs 可选：声明后详情弹窗自动生成对应参数滑块
  inputs: [
    { key:'R', label:'曲柄半径 r', min:10, max:30, step:1, value:24 },
    { key:'L', label:'连杆长度 L', min:52, max:80, step:1, value:52 }
  ],
  // p 接收 inputs 中的值；通用控件（动画速度 / 整体缩放）由弹窗自动注入
  build(svg, p = {}) {
    const R = p.R ?? 24;     // 未指定参数时使用默认值
    const L = p.L ?? 52;
    // 1. 用 el() 在 svg 中创建机构图元（几何常量改为读参 p.*，即可参数化）
    // 2. 返回 function(t)，每帧按运动学更新图元属性
    return (t) => { /* 更新图元 */ };
  }
}
```

在 `CATS` 数组（若为新增分类）中加入分类即可；跑马灯词条由 `MECHANISMS` 自动生成，无需手动维护。
